# Configuration files
This folder contains mostly Klipper configuration files and non-Klipper configuration files stored in /Non-Klipper folder.

## Requirements for Non-Klipper configuration files
* This requires Adafruit CircuitPython firmware.
* For RealEstate display mount:
    * Please refer to page 44 of [RealEstate G2.1 assembly manual](https://github.com/Bunny350/OITSWILLIAMV2/blob/For-Voron-2.4/Manuals/realestate-generation-2-1-assembly-guide.pdf) on how to use these files.
    * Please refer to page 17 for wiring illustration or page 12 for wiring diagram.
