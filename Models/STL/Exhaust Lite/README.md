## Directory printing guide for ELG2
This page shows what method you should use when choosing. Directories that are not in list must have all parts printed (excluding another directory in it).

### Legend: Parent / Child / Child / [Variants] ...

### Directories that need all parts in it printed:
* Filter cartridge
* LED Back (opaque visibilities)

### Directories that let you print either part by back panel thickness:

* Body unit / Exhaust spacer
* LED Back / [Back panel thickness (4 / 6mm)]

### Directories that let you print one of either part by back panel thickness and max cabling depth:

* Cable cover / [Back panel thickness (4 / 6mm)] / [Depth (10 / 15mm)]

### Directories that let you print one of either parts by screw type of coupler:

* Bowden coupler
	* Currently, one with runout sensor only supports 1/8" BSPP coupler.

### Directories that let you print one of either part by screw type:

* Unit cover

### Directories that let you print one of either part by whether should you embed a webcam to ELG2:

* Chamber cover

### Directories that let you print for one of either variant of webcam you mount, or not required if not installing it:

* Webcams
