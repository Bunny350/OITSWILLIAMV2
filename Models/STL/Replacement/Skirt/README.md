# The skirt folder

This folder contains skirt parts intended to be placed on V2 in 150mm build volume.

## Side skirts
The side skirts (side_skirt_a_150_mesh.stl and side_skirt_b_150_mesh.stl) needs processing settings changed prior to print:

* Zero top and bottom layers
* 6 wall count, if using 0.4mm nozzle, or 2.4mm walls.
* Sparse infill density can be between 15% and 50%.
* You can choose what infill pattern that fits for you.
* Might as well adjust the infill direction in angle if you are not satisifed during preview before print. 

If the printer is going to be installed with banger speakers, then you may only print a pair, otherwise you may print two pairs.

## Front skirt
The front skirts (front-skirt-150mm-mod-left.stl and front-skirt-150mm-mod-right.stl) can follow the normal print settings, but it does not have any screws to hold, as it might otherwise weaken the part significantly. Because of this, I made a workaround where the front clips are attached to the bottom panel via screws instead of the multi-sided tape.
