This folder contains a full assembly of Voron 2 in 150mm build volume and mods + upgrades that empower it.

## Included mods
* RealEstate G2
* Exhaust Lite G2 with camera
* NUC-specific skirt

## Included upgrades
* [Voron Tap](https://github.com/VoronDesign/Voron-Tap)

## Why is the STEP CAD file compressed?
This is because the STEP file itself is 158.6MB, which is bigger than usually allowed per-file size. The compressed file is just around 30MB. And the compressed file should **not be locked with a password**, otherwise **do not access it**.
