# Parts printing
This page guides users on printing required parts.

## I want it to live, entertain everyone, be like a boombox and treat it like a computer
The required parts are:
* RealEstate G2
* NUC-specific skirt
* Banger speakers
* 2x 60mm fan mount for 150mm Voron printers ([STL](https://github.com/Bunny350/OITSWILLIAMV2/tree/For-Voron-2.4/Models/STL/Replacement)) ([CAD](https://github.com/Bunny350/OITSWILLIAMV2/tree/For-Voron-2.4/Models/CAD/VORON2.4-150mm/150mm%20mod%2060mm%20fan%20mount))
* 1 pair of normal side skirts ([STL](https://github.com/Bunny350/OITSWILLIAMV2/tree/For-Voron-2.4/Models/STL/Replacement/Skirt))
* Tracker mounting is generally recommended ([STL](https://github.com/Bunny350/OITSWILLIAMV2/tree/For-Voron-2.4/Models/STL/Tracker%20mount)) ([CAD](https://github.com/Bunny350/OITSWILLIAMV2/tree/For-Voron-2.4/Models/CAD/Tracker%20mount))

## I don't care about making it an enthusiastic computer, I've just want it to print, follow as many components as the original, but small
The required parts are:
* SBC-specific skirt ([STL](https://github.com/Bunny350/OITSWILLIAMV2/tree/For-Voron-2.4/Models/STL/Electronics%20mounts/Computer%20mounting/SBC)) ([CAD](https://github.com/Bunny350/OITSWILLIAMV2/tree/For-Voron-2.4/Models/CAD/VORON2.4-150mm/SBC-specific))
* 2x 60mm fan mount for 150mm Voron printers ([STL](https://github.com/Bunny350/OITSWILLIAMV2/tree/For-Voron-2.4/Models/STL/Replacement)) ([CAD](https://github.com/Bunny350/OITSWILLIAMV2/tree/For-Voron-2.4/Models/CAD/VORON2.4-150mm/150mm%20mod%2060mm%20fan%20mount))
* 2 pairs of normal side skirts ([STL](https://github.com/Bunny350/OITSWILLIAMV2/tree/For-Voron-2.4/Models/STL/Replacement/Skirt))
* Tracker mounting is generally recommended ([STL](https://github.com/Bunny350/OITSWILLIAMV2/tree/For-Voron-2.4/Models/STL/Tracker%20mount)) ([CAD](https://github.com/Bunny350/OITSWILLIAMV2/tree/For-Voron-2.4/Models/CAD/Tracker%20mount))

## Required spares
This mod requires a dedicated / external power supply, of:
* At least 300W for one with NUC inside,
* Or at least 200W for one with SBC.

## Procedure
This mod may intersect with the original assembly manuals: Voron 2 (2.4r2), Stealthburner, Tap. Please check this if you are building from start to finish.

* The mod may not use DIN-based electronics mounting, especially where such may conflict with NUC skirt.
* This mod recommends DC-powered bed, which removes the requirement of solid state relay (SSR).
* Voron 2 assembly manual from start to page 146,
* Voron Stealthburner assembly manual, from start to page 58, if using such tool head,
* Voron Tap assembly manual, if using such upgrade, otherwise proceed from page 59 to 67 of Stealthburner manual (if using such tool head),
* Pages 148 and 149 of Voron 2 assembly manual, 
* OitswilliamV2 NUC skirt, from start to page 25, if using NUC, or original assembly manual from pages 150 to 152 if using SBC,
* Pages 158 to 161 of Voron 2 assembly manual, if not using Voron Tap upgrade,
* Pages 162 to 164 of Voron 2 assembly manual,
* Pages 180 to 209 of Voron 2 assembly manual, AC part may be excempted,
* Pages 210 to 237 of Voron 2 assembly manual,
    * Pages 211, 214 to 216, and 220 to 221 contains monochrome LCD display,
    * If you are switching to RealEstate display, these sections need to be ignored and then referred to OitswilliamV2 RealEstate display assembly manual,
    * Item tracker mounting manual, if installing an item tracker,
    * The skirt mounting part of OitswilliamV2 NUC skirt, from pages 26 to 28, if already using NUC,
* Pages 238 to 249 of Voron 2 assembly manual, if using the original enclosing,
* Pages 250 to the end of Voron 2 assembly manual.
